# Resume Skill

一个用于创建、改写、排版、本地化和导出简历的 Codex Skill 项目。它不限定语言，也不限定 IT 行业，可以根据目标岗位、目标地区和目标语言自动调整简历结构、表达重点和经历模块，适用于技术、运营、销售、市场、产品、设计、行政、人事、财务、客服、教育、制造、服务业以及转行求职等场景。

## 适用场景

- 从零创建一份任意目标语言的简历。
- 根据已有简历进行优化、改写和排版。
- 针对不同岗位生成定制版本。
- 将简历本地化为中文、英文或其他目标语言。
- 为行业小白补充真实口径的实践经历。
- 生成 Markdown、HTML、DOCX、PDF 等简历交付物。
- 对比不同视觉模板，选择适合投递或面试展示的版本。

## 核心原则

- 保留真实经历，不虚构公司、客户、上线项目、商业数据或职位级别。
- 没有正式项目时，可以使用真实可解释的经历模块，例如个人练习项目、模拟业务项目、课程项目、作品集项目、校园经历、志愿服务经历等。
- 简历表达围绕目标岗位调整，不把所有岗位都写成技术项目经历。
- 简历语言跟随用户需求；如果没有指定语言，则默认匹配用户沟通语言。
- 面向不同地区时，适配常见表达、日期格式、页面尺寸和 section 命名习惯。
- 优先保证清晰、可读、适合打印和投递，再考虑视觉风格。
- 个人隐私信息只放在最终私有交付物中，不写入可复用模板或公开示例。

## Skill 内容

- `resume-builder/SKILL.md`：Skill 的主说明，定义能力范围、工作流、写作规则、布局规则和验证要求。
- `resume-builder/references/resume-workflow.md`：完整的简历访谈、策略、经历包装、内容改写和最终检查流程。
- `resume-builder/references/resume-profile-schema.md`：可复用简历数据结构，支持多行业、多岗位和小白实践经历。
- `resume-builder/scripts/create_profile_template.py`：生成空白简历 JSON 模板。
- `resume-builder/agents/openai.yaml`：Skill 在 Codex/OpenAI 环境中的展示信息。

## 生成简历数据模板

如果需要从结构化数据开始，可以运行：

```powershell
python resume-builder\scripts\create_profile_template.py profile.json
```

生成的 `profile.json` 会包含目标语言、目标岗位、个人信息、技能、工作经历、项目经历、通用经历模块、教育、证书和隐私设置等字段。

## 小白无项目经验怎么处理

本项目支持自动补充“岗位适配型经历模块”，但会保持真实口径。例如：

- 销售岗位：模拟客户开发清单、产品卖点梳理、跟进话术设计、异议处理复盘。
- 运营岗位：内容选题表、社群活动方案、用户问卷分析、活动复盘报告。
- 行政岗位：会议纪要模板、档案整理流程、物资台账、面试邀约流程。
- 财务岗位：Excel 费用台账、模拟对账、基础凭证整理、经营数据汇总。
- 客服岗位：常见问题知识库、投诉处理流程、服务话术优化、工单分类复盘。
- 设计岗位：海报、详情页、品牌视觉练习、改版案例、作品集项目。
- 教育岗位：试讲教案、学生错题分析、课程讲义、学习反馈记录。
- 技术岗位：管理系统、数据看板、小程序、自动化脚本、接口或数据库练习。

这些内容应标注为“个人练习项目”“模拟业务项目”“课程项目”“作品集项目”等，不能包装成真实公司项目。

## 使用建议

开始生成简历前，至少明确：

- 目标岗位和行业。
- 目标语言，例如中文、英文、日文、法文，或其他任意语言。
- 目标地区或投递国家，如果需要按当地简历习惯调整。
- 是否应届、转行、实习、社招或自由职业。
- 真实经历材料有哪些。
- 是否有证书、作品、课程、兼职、社团或志愿经历。
- 简历投递对象是 HR、业务负责人、专业面试官还是熟人内推。

信息越具体，生成出的简历越能贴近岗位要求。

## 验证要求

生成或修改简历后，应尽量完成以下检查：

- 文案没有错别字、日期冲突或虚假表述。
- 技能与经历能够互相支撑。
- PDF/DOCX 打印布局没有文字裁切、遮挡或页数异常。
- HTML 简历在浏览器中可读，移动端和桌面端不出现明显溢出。
- 联系方式和隐私信息只出现在最终私有版本中。
